The is a controlled vocabulary that describes functions, roles, and locations of gene products. A widespread application is the identification of annotation-enriched GO terms in a list of genes that share some biological characteristic, the so-called study set (e.g., genes that are overexpressed in an experiment), compared to a larger list of genes, the population set (e.g., all genes measured in the experiment). These terms are often interpreted as representing the biological features of the genes in the study set.

This application is the third edition of the Ontologizer, following in 2004 and in 2008, both of which were created in Java. Ontologizer 3.0 was created as a Tauri application that makes use of an efficient backend in Rust and a modern frontend using the Angular framework.

To run an enrichment analysis, Ontologizer requires four inputs:

  1. Gene Ontology (GO) — is a standardised vocabulary of biological knowledge, made of terms connected in a hierarchy by defined relations organized into three aspects biological processes, molecular functions, and cellular components. Downloaded automatically or provided locally.
  2. GO association file — a species-specific file linking GO terms to genes or gene products. Downloaded automatically for common organisms, or provided locally.
  3. Population set — the full set of genes measured in your experiment. Experiment-specific; must be provided locally.
  4. Study set — a subset of the population sharing a biological characteristic of interest (e.g. differentially expressed genes). Experiment-specific; must be provided locally.

Together, these inputs allow Ontologizer to test whether certain GO terms are overrepresented in the study set compared to the population set.

Ontologizer accepts the standard file formats published by the Gene Ontology Consortium and expects gene lists as plain text:

  • Ontology — OBO format (.json), as distributed by the GO Consortium.
  • Annotations — GAF format (.gaf, gaf.gz), the species-specific gene association files.
  • Gene lists — plain-text files with one gene symbol or identifier per line, matching the namespace used in the GAF.

For supported organisms, the ontology and annotation files can be fetched on demand from the Files page; otherwise drop in your own copies.

Ontologizer implements two complementary approaches to identify GO terms enriched in the study set:

  • Hypergeometric test — the standard frequentist overrepresentation analysis, applied per term with multiple-testing correction.
  • MGSA — Model-Based Gene Set Analysis, a Bayesian model that jointly evaluates all terms and returns a posterior probability of activation per term. See .

For full descriptions of the assumptions, parameters, and trade-offs, refer to the cited publications.

} @case ('bar-plot') {

The primary output of Ontologizer is a table of all tested GO terms, sorted by significance.

  • Term Label — the full name of the GO term.
  • Aspect — the subontology the term belongs to (Molecular Function, Biological Process, or Cellular Component).
  • GO ID — the unique Gene Ontology identifier.
  • Significance — either an adjusted p-value (Statistical testing) or a posterior probability (Bayesian inference).
  • Study genes — the genes from the study set annotated to the term.

The table can be exported via the Save Results button.

From this table Ontologizer derives two figures, both scoped to the currently selected aspect and term subset:

  • GO graph — renders the selected terms together with their ancestors, exposing the hierarchical context within the chosen subontology.
  • Bar chart — visualises the chosen significance statistic across the selected terms for quick comparison.
