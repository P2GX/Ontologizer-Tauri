The is a controlled vocabulary that describes functions, roles, and locations of gene products. A widespread application is the identification of annotation-enriched GO terms in a list of genes that share some biological characteristic, the so-called study set (e.g., genes that are overexpressed in an experiment), compared to a larger list of genes, the population set (e.g., all genes measured in the experiment). These terms are often interpreted as representing the salient biological features of the genes in the study set.

This application is the third edition of the Ontologizer, following in 2004 and in 2008, both of which were created in Java. Ontologizer V3 was created as a Tauri application that makes use of an efficient backend in Rust and a modern frontend that uses the Angular framework.

To run an enrichment analysis, Ontologizer requires four inputs:

  1. Gene Ontology (GO) - a hierarchy of terms describing biological processes, molecular functions, and cellular components. Downloaded automatically or provided locally.
  2. GO association file - a species-specific file that links GO terms to genes or gene products. Downloaded automatically for common organisms, or provided locally.
  3. Population set - the full set of genes measured in your experiment. Experiment-specific; must be provided locally.
  4. Study set - a subset of the population set sharing a biological characteristic of interest (e.g. genes that are differentially expressed).Experiment-specific; must be provided locally.

Together, these inputs allow Ontologizer to test whether certain GO terms are overrepresented in the study set compared to the population set.

Statistics & Methods

Ontologizer provides two methods to test for term overrepresentation The Term-for-Term method with Bonferroni correction for multiple testing is the classic GO overrepresentation algorithm.

Ontologizer additionally implements the parent-child algorithms and Model-Based Geneset Analysis (MGSA).
