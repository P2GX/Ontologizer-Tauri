Welcome to Ontologizer

Ontologizer performs GO term overrepresentation analysis on a study gene set against a population gene set.

Two complementary methods are provided:

  • Statistical Testing — evaluates each term independently using Fisher's exact test.
  • Bayesian Inference — evaluates all terms jointly using model-based gene set analysis (MGSA).

For details on the methods and file formats, visit Help. For questions or feedback, see Contact.
